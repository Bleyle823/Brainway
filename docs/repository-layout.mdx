# Repository layout

| Path | Description |
|------|-------------|
| `Brainway/` | Web application — TanStack Start, Vite, Cloudflare Worker |
| `docs/` | Documentation (including these Mintlify pages) |
| `plugins/runway/` | Hermes — Python Runway plugin |
| `plugins/plugin-runway/` | ElizaOS — TypeScript Runway plugin |

The top-level [`README.md`](https://github.com) in the repo root links all of these together.
