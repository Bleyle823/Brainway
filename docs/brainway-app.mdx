The **Brainway** product is the web application in [`Brainway/`](https://github.com/Bleyle823/Brainway/tree/main/Brainway): **TanStack Start**, **React 19**, **Vite 7**, **Tailwind v4**, targeting **Cloudflare Workers** with optional **Vercel (Nitro)**.

## Quick start

```bash
cd Brainway
npm install
cp .env.example .env.local   # Windows: copy .env.example .env.local
# Set RUNWAYML_API_SECRET at minimum
npm run dev
```

Open the URL from the dev server (typically `http://localhost:5173`).
