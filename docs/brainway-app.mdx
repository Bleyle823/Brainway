# Brainway application

The product **Brainway** lives in `Brainway/`. It targets neurodivergent learners with profile-driven accessibility, Runway-powered video tooling, educator flows, live avatar sessions, and a community surface.

## Quick start

From the `Brainway/` directory:

```bash
npm install
npm run dev
```

See `Brainway/README.md` in the repository for architecture, environment variables, scripts, routing, and Cloudflare deployment.
