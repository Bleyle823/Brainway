# Brainway documentation

This site is generated with [Mintlify](https://mintlify.com). Configuration lives in [`docs.json`](https://mintlify.com/docs/organize/settings) at the **repository root**; MDX content is in this `docs/` folder. The Mintlify assistant uses [`.mintlify/Assistant.md`](https://mintlify.com/docs/assistant/customize) (not served publicly).

## What is in this repo?

- **Brainwave** — TanStack Start web app for calm, sensory-aware learning experiences (`Brainway/`).
- **Docs** — This documentation folder plus the legacy [`README`](https://github.com) index.
- **Plugins** — Runway integrations for Hermes (Python) and ElizaOS (TypeScript) under `plugins/`.

Use the sidebar to explore layout, the web app, and plugins. For the full app guide, see the Brainwave README in the source tree.
