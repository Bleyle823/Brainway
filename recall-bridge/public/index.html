Brainwave Recall bridge

This service joins Zoom / Google Meet / Microsoft Teams via Recall.ai and drives Runway Characters (bot.html). There is no interactive UI here — Brainwave’s /meet page calls this API.

Recall will reject localhost in PUBLIC_URL (403 request_blocked). Set PUBLIC_URL to an https:// tunnel URL from npm run tunnel.

Useful paths

  • /bot.html — Recall loads this as the bot camera page (needs ?session=… from an active session).
  • POST /api/start — begin a session (requires Runway headers).
  • GET /api/sessions/:id — session status and logs.
  • GET /api/health — liveness check.

Set PUBLIC_URL in .env to this server’s public HTTPS origin so Recall can reach /bot.html and WebSockets.
